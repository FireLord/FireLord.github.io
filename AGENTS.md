# Portfolio: Aman Kumar

Personal portfolio and blog. Next.js 16 (App Router), React 19, Tailwind CSS v4, Fumadocs MDX for the blog. Dark, single theme.

## Package manager: Bun only

- Use `bun install`, `bun add`, `bun run <script>`. Never use npm, yarn or pnpm, and never create `package-lock.json`, `yarn.lock` or `pnpm-lock.yaml`.
- `bun.lock` is committed. `bunfig.toml` enforces a 24h `minimumReleaseAge` on new package versions; don't bypass it.

## Commands

```bash
bun run dev      # next dev
bun run build    # next build (also regenerates .source/ for the blog)
bun run start    # serve the production build
bun run lint     # eslint .
bun run format   # prettier --write .
```

Run `bun run lint` and `bun run build` before calling a change done. There is no test suite.

## Layout

```
src/app/                 routes: / (home), /blog, /blog/[...slug], not-found
src/app/globals.css      Tailwind v4 theme tokens (@theme inline) and custom utilities
src/components/home/     home page sections; content lives in home-data.ts
src/components/ui/       shadcn/ui primitives (add via shadcn, don't hand-edit)
src/lib/blog.ts          Fumadocs loader, sorting and pagination
content/blog/*.mdx       blog posts (frontmatter: title, description, date like "2025.03", read like "8 min")
public/                  static assets, including aman_kumar_resume.pdf
.source/                 generated by fumadocs-mdx, gitignored, never edit
```

## Conventions

- Site content (projects, links, stack, resume URL) is data in `src/components/home/home-data.ts`. Edit it there, not inside section components.
- Import with the `@/` alias (maps to `src/`).
- Colors and radii come from CSS variables in `globals.css`. Use the tokens (`bg-surface`, `text-muted-foreground`, `var(--ember)`), not raw hex values.
- Components are server components by default. Add `"use client"` only where state, effects or browser APIs are needed (for example `work-section.tsx`).
- Respect `prefers-reduced-motion` for any new animation.
- Prettier and ESLint are configured; match the existing style instead of reformatting unrelated code.

## Resume

The resume PDF is `public/aman_kumar_resume.pdf` and is linked through `RESUME_URL` in `home-data.ts`. To update it, replace the file and keep the same name so the link and any shared URLs keep working.
